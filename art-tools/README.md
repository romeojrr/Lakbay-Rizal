# art-tools — how the Lakbay Rizal pixel art is made

Everything in `../assets/` was generated by these scripts. Use them to make new scenes in the same style.

## Setup
```
pip install pillow numpy global-land-mask
cd art-tools && mkdir -p out
```

## Characters
`python3 chars.py` writes `out/sheet.png` with every variant. `python3 export_sprites.py` writes the dialogue sprites added in v2.1 to `out/sprites/`. New options: `glasses=True`, `cape=` (Dominican habit), `hat='salakot'`, `dress='kimono'`. Build a new character by calling
`man(...)`, `woman(...)` or `child(scale='boy' | 'small', ...)` with clothing options (see the docstrings and the examples at the bottom of `chars.py`).

## How the style works (keep to it)
- `artkit.Canvas` stores a ramp id and a tone (0–6) per pixel. Light, shade and texture change tones; colors never blend.
- `ramp()` makes 7-tone hue-shifted ramps. Skin uses the hand-picked `SKIN_RAMPS` in `chars.py`.
- `solid()` shades a shape with light from the upper left. Textures: bricks, dressed stone, planks, clay tiles, nipa thatch, cobbles.
- `gradient()` makes banded skies with dithering only at band edges. `lamp_glow()` adds dithered light pools.
- `grade_fn()` gives each scene its mood (morning, dusk, winter, golden hour) by tinting the palette.
- Characters stand with their feet at y ≈ 206–207. Paste adults at `y = 207 − 75`, boys at `207 − 60`, small children at `206 − 45`.

## Making a new scene
1. Copy the closest `scene_*.py` (indoor → Berlin, street → Madrid/Manila, rural → Calamba/Dapitan).
2. Change the grade, sky, buildings and props to match the place and year (SRS §7.4). Check the anachronism list (SRS §7.5).
3. Render, open the 3× preview, fix what looks wrong, repeat.
4. Copy the PNG to `public/assets/scenes/` and point the stop's `scene.image` at it.

## Maps, builder art, stamp icons (`legacy-v1/`)
- `terrain.py`: renders a region map from real coastlines (`global-land-mask`). `lakes=[polygon]` paints lakes the dataset misses (Laguna de Bay is done this way).
- `gen_map.py` (Europe), `gen_ph.py` (Philippines + Manila inset), `gen_asia_america.py` (Asia and America; the Great Lakes are drawn with `lakes=`), `gen_dapitan.py` (top-down builder art), `gen_clinic.py` (the octagonal Casa Redonda clinic), `gen_icons.py` (first 8 stamps), `gen_icons2.py` (the other 17 stamps and all 24 item icons).
- `gen_asia_america.py` prints each town's pixel position in % — the app computes pins from lat/lon itself (SRS §8.6), so these are only for checking.

## Portraits (v2.3)
`python3 portraits.py` draws the 24 close-up portrait sheets into `out/portraits/` (256 × 384: 4 frames × 6 moods of 64 × 64; see SRS §7.10) and a contact sheet `out/portraits_contact.png`. Requires `pillow numpy matplotlib`. To adjust a character, edit its entry in `SPECS` and run the script again.
