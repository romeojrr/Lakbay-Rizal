# Decisions

One line per judgment call: date — decision — reason.

- 2026-11-25 — Starter pack flattened into the project root (assets/, content/, art-tools/, reference/, CLAUDE.md next to src/). — One folder to open; CLAUDE.md loads automatically.
- 2026-11-25 — The project has its own git repo inside Desktop/Lakbay-Rizal. — The home folder is also a git repo; keep this project's history separate.
- 2026-11-25 — `assets/` is the source of truth; `public/assets/` is generated by `scripts/copy-assets.ts` (runs before dev, build and test) and is gitignored. — Avoids two copies of the art drifting apart. Put new art in `assets/`, not `public/assets/` (this replaces step 4 of SRS §7.9).
- 2026-11-25 — Header Passport count is a fixed "0/25" in M0. — Progress store and content arrive in M1/M4; the total will come from the stops in content.
- 2026-11-25 — Region tab list is hard-coded in `RegionTabs.tsx` for M0. — `regions.json` is created in M1.
- 2026-11-25 — At ≤ 640 px the region tabs scroll sideways instead of wrapping. — SRS §5.2 asks for horizontal scroll; FR-1 allows either.
- 2026-11-25 — Header tabs and links have a 44 px minimum height. — SRS §5.2 touch targets; the mockup's tabs are about 40 px.
- 2026-11-25 — Header tab border color `#5A5266` added as token `--ink-line`. — Used in Main.dc.html but not listed in SRS §5.3.
- 2026-11-25 — Kept React Router 6 despite two moderate `npm audit` advisories (backslash open redirect in `<Link>`, SSR hydration). — SRS §8.1 picks v6; our links are fixed app paths and we do not use SSR. Revisit at M8.
- 2026-11-25 — ESLint pinned to v9. — eslint-plugin-react and eslint-plugin-jsx-a11y do not support ESLint 10 yet.
- 2026-11-25 — `npm test` runs Vitest only; Playwright runs with `npm run test:e2e`. — Matches the check sequence in CLAUDE.md and keeps the unit loop fast.
- 2026-11-25 — `public/content/*.json` is now the content the team edits; `content/` keeps the original seed. `npm run convert-seed` refuses to overwrite existing files unless run with `--force`. — Re-running it by accident must not erase fact-checking work.
- 2026-11-25 — In `regions.json`, regions are an array in tab order (Philippines, Asia, Europe, America), each with an `id`. — The seed used an object in a different order; an array makes the tab order explicit.
- 2026-11-25 — Content JSON objects are strict: an unknown key is an error. — Catches misspelled field names, which would otherwise be silently ignored.
- 2026-11-25 — Story length: outside 90–170 words is a warning for drafts and an error for verified stops. — Literal reading of SRS §6.2; the target stays 100–150.
- 2026-11-25 — Quiz questions need exactly 4 options. — FR-40 says "four options each".
- 2026-11-25 — The final stop is the one with the highest `order` (today Bagumbayan). — Lets GD-6 rules work without hard-coding an id.
- 2026-11-25 — Extra validation beyond SRS §6.2: stop coordinates must fall inside their region map; scenes must be 384 × 216 and icons 26 × 26; region maps must match their declared size; verified stops need page numbers for print books and at least one Tier 1/2 source; sources on Scribd, SlideShare, Prezi, Course Hero, Brainly or Wikipedia are rejected. — These come from SRS §7.1, §8.6 and §14.1 and are cheap to check.
- 2026-11-25 — A dialogue with `dramatized: false` in which a character speaks gives a warning, not an error. — SRS §6.4 requires the flag, but a documented quote may be shown as not dramatized; a person must decide.
- 2026-11-25 — Asset paths are checked against `assets/` (the source that is copied to `public/assets/`). — Validation does not depend on copy-assets having run first.
- 2026-11-25 — Content is validated in the browser only in development; production trusts the build-time check. Zod is loaded with a dynamic import so it is not in the production bundle. — SRS §8.3 ("validates again (dev only)") and NFR-1 bundle size.
- 2026-11-25 — `characters.json` has an optional `portrait` crop (`left`, `top`, `width`, `height`); none is set yet. — The seed has no crops; M3 will use the SRS §5.4 default and add crops only where a sprite needs one.
- 2026-11-25 — Preview mode (`?preview=1`) is remembered for the browser tab in sessionStorage; `?preview=0` turns it off. — Otherwise the flag would be lost on the first link click.
- 2026-11-25 — The root route loads content with a React Router loader and never revalidates it. — Content is static; one fetch per visit.
- 2026-11-25 — When content cannot load, the page shows "The journey could not load" with a Try again button (details only in development). — No "game over" states (GD-5); keep the message friendly.
- 2026-11-25 — The header's Passport total now counts the stops this build may show (25 in development, 0 in a production build with no verified stops). — FR-62.
- 2026-11-25 — Added `place.label` (≤ 16 characters, e.g. "Berlin") to every stop; values taken from each stop's `place.then` and kept in `scripts/convert-seed.ts`. — Pins, cards and lists need a short name; cutting `place.then` at a comma gives "Ateneo Municipal" or "Hong Kong (British colony)".
- 2026-11-25 — Progress store (Zustand) added in M2 but kept in memory only; saving to localStorage comes with M4. — The map needs the mode and completed stops now; persistence, migrations and corrupt-data handling are M4 work. Guided/Free resets on refresh until then.
- 2026-11-25 — Cluster rule: in a region with an inset, every stop inside the inset bounds forms one cluster that opens the inset; elsewhere, pins closer than 8 px on the native map image are grouped, and the cluster opens a small list. — FR-15. Europe gets three clusters (Paris ×2, Heidelberg + Wilhelmsfeld, Brussels + Ghent).
- 2026-11-25 — The Manila-area cluster shows 8 (the number of stops), not 3 as in the FR-15 check. — The check was written when only Calamba, Biñan and Manila were stops; the inset still shows 3 town markers.
- 2026-11-25 — "Open" pin state for stops unlocked in Free mode but not done: theme color with a dark dot. — FR-12 only defines done / current / locked.
- 2026-11-25 — Pin accessible names: "Berlin, 1887, current stop", "Paris, 1885, completed", "Locked stop, 1888". — FR-13; the year tells the two Paris stops apart, and locked pins do not reveal the place, matching their "?" label.
- 2026-11-25 — The journey list shows place names for locked stops too. — Matches Main.dc.html (Leitmeritz and London are listed while locked).
- 2026-11-25 — Timeline: the year starts at the next stop's year; "where Rizal was" in a year is the last stop (in order) that started by then; the map switches region only when the player moves the slider. Pins are dimmed when every stop in them is after the year; the travelled line stops at the year; the dashed line ahead always shows. — SRS §3.4 / FR-21.
- 2026-11-25 — Era ticks sit at their real years (1872, 1882, 1892); the labels below are spread evenly as in the mockup. — The mockup's second tick (85.7 %) does not match 1892.
- 2026-11-25 — Zoom grows the map inside a scrolling viewport (not a CSS transform), so pins keep their size and stay aligned; touch scrolls natively, mouse drags to pan. On small maps only the current and highlighted pin labels are shown. — FR-16; labels would cover each other on a 300 px map.
- 2026-11-25 — Theme chips use darker backgrounds for Study (#2C5FB8) and Cause (#B23A2B). — White and ink text both fall below 4.5:1 on the SRS theme colors; pins and swatches keep the original colors.
- 2026-11-25 — `/` redirects to the last region viewed, or the region of the next stop. — FR-2 "map, last region"; a redirect also highlights the right tab.
- 2026-11-25 — Not built yet: the "↖ Hong Kong · locked" off-map hint from Philippines.dc.html. — Not in the FR list; can be added in M7 with the Asia map.
- 2026-11-25 — Stop page keeps the normal header (with region tabs) and puts "◀ Back to map" above the scene; the mockup puts the back link in the header instead. — One shared header is simpler; the back link is still the first thing on the page.
- 2026-11-25 — Back links go back one step in the browser history when the visit has one, else to the stop's region map. — FR-3: map → stop → quiz → back → back must land on the same map.
- 2026-11-25 — The narrator's portrait is a pixel-SVG book, not `characters.narrator.icon` (the Bagumbayan sampaguita). — SRS §3.6 says "Narrator (book icon)"; a flower from the final stop on every stop would be confusing.
- 2026-11-25 — Default portrait crop: sprite at 3×, centred (+3 px), top −18 px for sprites 60 px or taller, −3 px for small children; `characters[].portrait` overrides it. — Gives the mockup's exact crop for 34 × 78 sprites and keeps child faces in frame.
- 2026-11-25 — The "…" bubble's bottom centre sits on the speaker anchor. — Anchors are near each speaker's head in the art.
- 2026-11-25 — Speaker names use #A4521A (mockup #B8601A is 4.37:1); the locked Quiz button uses --muted text. — 4.5:1 contrast.
- 2026-11-25 — The Sources card shows the first two citations and a "Show all N sources" button; online sources get a "Read online" link (opens a new tab). — Berlin has 7 sources; all seven at once make the panel very long. Links are navigation, not runtime requests (NFR-5).
- 2026-11-25 — The stop title (e.g. "The Noli is printed") and date range appear in the "This stop" card; the scene badge (h1) shows place · year as in the mockup. — The mockup has no place for the title; players should still see it.
- 2026-11-25 — Read more uses the native `<dialog>` with an added Tab/Shift+Tab cycle. — Native modals let Tab escape to the browser UI; FR-33 asks for a focus trap.
- 2026-11-25 — A locked stop opened by URL (Guided) shows "This stop is still locked" with a link to the next stop; outline stops show "coming soon". — FR-18.
- 2026-11-25 — On the final stop (no quiz) the Epilogue card (timeline + credits links) appears once the dialogue is finished. Completing the stop and the plain passport page come with the progress actions in M4. — GD-6.
- 2026-11-25 — Progress is saved with Zustand `persist` under `lakbay-rizal:v1`; the storage adapter itself parses, migrates (`store/migrations.ts`) and checks the save, and a damaged save is copied to `lakbay-rizal:v1:corrupt` before the game starts fresh. The check is hand-written, not Zod. — FR-70 / §8.5; Zod stays out of the production bundle (NFR-1).
- 2026-11-25 — Blocked or full storage never stops the game; progress then lasts for the visit only, with no notice. — Private browsing should still be playable.

A right answer needs "Next question ▶"; the last one shows "See your reward ▶". — FR-41 and FR-42 together; no penalty (GD-5).
- 2026-11-25 — The quiz opens only after the stop's dialogue is finished (stop visited); otherwise it links back to the story. — FR-31 "last line … unlocks Quiz".

- 2026-11-25 — Passport traveller details come from content: name and sprite from `characters.rizal`, "Born" and the passport number from the first stop. — FR-60: no historical text in components.

- 2026-11-25 — Theme badges are dimmed until every stop in the theme is done, then light up with a gold ring and ★. — FR-52 ("lights up when complete"); the mockup lit any badge above 0.
