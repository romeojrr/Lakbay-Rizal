# Mockup reference

These are the approved screen designs, saved from the design canvas. Each `.dc.html` file is plain HTML with inline styles plus a small logic class at the bottom (the canvas runtime that runs them is not included). Read them for layout, sizes, colors and copy; rebuild them as React components (SRS §5). Image paths point into `../../assets/`.

|---|---|
| Main.dc.html | Europe region map, next-stop card, journey list, timeline |
| Philippines.dc.html | Philippines map, cluster pin, Manila inset, Dapitan card |
| Story.dc.html | Stop scene + dialogue + info cards |
| Quiz.dc.html | Quiz |
| Passport.dc.html | Passport book |
| Dapitan.dc.html | Dapitan builder |
